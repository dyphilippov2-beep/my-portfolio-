Добавить актив

Цены покупки и текущая цена здесь — чистые цены в рублях, без НКД. Изменение цены показывается отдельно от НКД.
Автоматического получения цены монет в этой версии нет. Укажите цену и источник; дата оценки сохранится.

Каждая запись сохраняется отдельно. Одинаковые бумаги объединяются только на экране. Исправляйте конкретную запись, чтобы не потерять другие покупки.

Настройки и данные

Блокировка интерфейса

PIN скрывает интерфейс, но не шифрует портфель. WebAuthn / Face ID не используется как имитация защиты. Для настоящей конфиденциальности требуется отдельное шифрование данных.

Повторная блокировка — после 1 минуты в фоне. Забытый PIN нельзя восстановить; заранее сохраните JSON-копию отдельно.

Очистка удаляет активы из текущей версии. Настройки PIN и данные старого приложения сохраняются.

Импорт скриншотов

Загружайте по одному счёту за раз. Повторные строки не складываются. Лоты не считаются штуками: количество нужно перевести по размеру лота. Неоднозначные названия и повторные позиции отмечены для проверки.

Замена меняет только выбранные бумаги. Если количество изменилось, неизвестная цена покупки не переносится из старого остатка. Остальные активы остаются.
